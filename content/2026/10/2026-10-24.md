## 构建者动态

### 1. OpenAI：Codex CLI 改进集中在长会话、配置复用与企业接入

OpenAI 的 Thibault Sottiaux 表示，Codex CLI 新增可复用 prompt 预设、内联模型与权限设置、企业 MCP 登录，并修复长会话恢复失败问题，加入 Windows 企业代理认证。他还称 CLI 使用量自 DevDay 以来翻倍；帖子没有说明统计口径和绝对规模，应将其视为团队自报数据。

另一条更新称，Codex 与 Work 在对话中调整 reasoning 设置时不再导致缓存失效，dots 通话连接也有所提速。对于重复执行的自动任务，值得关注的是配置复用和长会话恢复是否能减少人工接手，而非仅看一次演示能否完成。

### 2. Replit：Chroma 团队加入，重点解决 agent 上下文与记忆

Replit CEO Amjad Masad 宣布欢迎 Jeff 和 Chroma 团队加入 Replit，称他们将帮助 agent 获得完成真实工作所需的上下文和记忆。原帖没有提供交易结构、金额或开源项目后续安排，因此不能据此补充收购细节。

观察：从一次性生成代码走向持续执行企业任务，模型需要知道已有决策、业务状态和历史操作。这次团队整合表明 Replit 正将上下文和记忆作为 agent 产品能力的一部分，但实际效果仍需产品发布与使用结果来验证。
https://x.com/amasad/status/2113736007111827606

### 3. Vercel：共享主机的缓存侧信道值得纳入 agent 威胁模型

Vercel CEO Guillermo Rauch 讨论了一类共享主机上的计时攻击：当两个 agent 位于同一台机器，一个可通过 CPU 缓存活动制造干扰，另一个通过测量计算与缓存访问耗时感知这种干扰。他将其描述为一种“吵闹邻居”攻击，并认为 agent 让过去被认为实施成本过高的攻击更值得认真对待。

Rauch 称 Vercel Sandbox 已采取实际可行的缓解措施，并配合持续监控与红队测试。这是供应商关于防护工作的说明，不代表风险已消除；他提出每个 agent 使用专用硬件的隔离思路，也强调了其经济代价。

技术观察：这里讨论的是共享硬件引入的信息通道，不是模型 KV cache 的容量优化。对 agent 基础设施而言，需要同时评估软件权限边界、共享硬件风险和隔离成本。
https://x.com/rauchg/status/2113759533801877920

### 4. Box：网络防御可能成为 agent 群体协作的重要市场

Box CEO Aaron Levie 预测，网络防御中的 agent 群体协作将成为 AI 的重要应用类别。他列举了代码与基础设施检查、风险组合测试和大量数据分析，认为这些场景可以利用更多计算覆盖人类来不及完成的检查。

这是对应用方向的判断，并非吞吐或防护效果的测量结果。值得跟踪的落地指标包括有效漏洞发现率、误报处理成本，以及修复后是否经过独立复核。
https://x.com/levie/status/2113738768645808277

这条消息确认的是人员变动。原帖没有宣布新公司、融资或产品，也不足以推断 Claude Code 的路线发生改变。

### 6. 机器人学习：扩大任务范围可能比逐个训练专用系统更有价值

SPC 合伙人 Aditya Agarwal 分享了 Sergey Levine 关于机器人学习的观点：AI 的一些重要进步来自共同解决多个问题，而非分别训练只处理单项任务的系统；类似思路也值得用于机器人。

这是一条研究方向层面的观点。feed 未提供具体实验、模型规模或成功率，不能把它扩展成“多任务训练已经全面优于专用系统”的结论。
https://x.com/adityaag/status/2113666947766169868

## 开源项目精选

**cloudflare/security-audit-skill（JavaScript）**：面向 coding agent 的多阶段安全审计技能；项目描述强调发现结果的独立验证和机器可读输出。可关注其如何把扫描、复核与报告连接成完整流程。
https://github.com/cloudflare/security-audit-skill

**anthropics/knowledge-work-plugins（Python）**：主要面向 Claude Cowork 知识工作者的开源插件集合，体现 agent 能力向具体办公任务封装的方向。

**NVIDIA/OpenShell（Rust）**：项目定位为自主 AI agent 的安全、私密运行时。该定位来自项目描述，不代表本报告对其安全隔离效果作出认证。
https://github.com/NVIDIA/OpenShell

**OpenBMB/VoxCPM（Python）**：项目介绍 VoxCPM2，强调无需 tokenizer 的多语言语音生成、声音设计与声音克隆。feed 没有提供质量或延迟基准，本期仅记录项目方向。
https://github.com/OpenBMB/VoxCPM

## 今日观察

**agent 的生产化要求正在变得更具体。** Replit 关注持续工作的上下文与记忆，Vercel 讨论共享硬件隔离，Cloudflare 的技能强调对审计发现进行独立复核。这几条动态共同指向一个工程问题：agent 不仅要完成任务，还需要在可管理的环境中保留状态，并让结果能够被检查。此处是基于上述材料的编辑判断，不是新增产品公告。
