## PODCASTS

Training Data：Parallel’s Parag Agrawal - Building a New Web for AI Agents

一句话结论：Parallel 的核心判断是，agent 会比人类高频得多地使用 Web，所以搜索引擎也要从“服务人点击”重构为“服务 agent 完成任务”。

Twitter 前 CEO、Parallel 创始人 Parag Agrawal 认为，传统搜索靠人类点击数据优化，但 agent search 应该依赖 agent feedback，而不是 human feedback。他把 Parallel 定位为“模型的补乘器”：不是训练一个 frontier model，而是把 Web 信息压缩、索引、排序，并把最相关的少量 token 送进 agent context window，让模型少读噪音、多做任务。

最有价值的一点是他的冷启动策略。Parallel 没有一开始就复制 Google 式全量搜索引擎，而是先做 search agent：在用户允许等待几十秒到数分钟的 deep research 场景里，用查询后的 crawling 和推理时间换取更少的前置索引成本。随着客户用例增加，它再逐步积累 eval、ranking 和 index 能力。这其实是 agent 时代搜索创业公司的典型路径：先替代人工研究流程，再逐步沉淀基础设施。

Parag 还有一个很锋利的判断：“human click data is a bug”。对 agent 来说，最好的结果不是加载快、适合人眼浏览、SEO 友好，而是权威、精确、可被模型直接使用的上下文片段。这会把搜索竞争从“网页排名”推向“上下文供给质量”。

## TODAY'S TAKEAWAY

今天的主线是 agent 产品从“会做事”进入“可长期协作”的阶段。Claude 统一 Chat 和 Cowork memory，Vercel 把安全执行和认证连接做成基础设施，Parallel 把搜索重新定义为 agent 的上下文供应链，Peter Yang 的医疗 skill 则展示了 skills 在真实生活高压场景中的落地方式。

一句话总结：agent 生态的竞争点正在从模型能力转向 memory、connectivity、eval、安全执行和垂直工作流封装。谁能把这些基础层做好，谁就更可能把 AI 从一次性问答变成长期工作伙伴。
