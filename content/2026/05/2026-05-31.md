## 官方博客

Claude Blog —《Claude Managed Agents 新功能：dreaming、outcomes 与多 agent 编排》

Anthropic 在 Managed Agents 中以研究预览形式推出了 "dreaming"（做梦）：这是一个定期运行的进程，会回顾 agent 过往的会话和记忆库，提取模式、整理记忆，让 agent 随时间自我改进。它能发现单个 agent 自己看不到的东西——反复犯的错误、多个 agent 收敛出的工作流、团队共享的偏好——你可以选择让它自动更新记忆，也可以先审核再生效。

同时面向开发者开放的还有两项能力："outcomes"（结果导向）让你写一份描述"什么算成功"的评分标准（rubric），由一个独立的评分器在自己的上下文窗口里评估输出，不受 agent 推理过程影响，不达标就让 agent 再来一遍。内测显示 outcomes 把任务成功率最高提升了 10 个百分点，最难的问题上收益最大；文件生成质量上 docx 提升 8.4%、pptx 提升 10.1%。"多 agent 编排"则让一个 lead agent 把大任务拆解、分派给各有模型/提示词/工具的专才 agent 并行处理。落地案例：Harvey 用 dreaming 让法律 agent 跨会话记住踩过的坑，完成率提升约 6 倍；Spiral by Every 的写作 agent 用 Haiku 跑 lead、Opus 跑起草子 agent，并用 outcomes 按编辑规范打分。
https://claude.com/blog/new-in-claude-managed-agents

## 播客

Unsupervised Learning Ep 87 — Gemini 联合负责人谈世界模型、RL 的下一个战场与持续学习

核心要点：通往 AGI 的关键缺口或许不是更大的模型，而是让模型像人一样"从经验中持续学习"——而这件事现在更可能通过"文件系统式"的外部记忆，而非改写权重来实现。

嘉宾 Oriol Vinyals 是 Google Gemini 的联合负责人（与 Noam Shazeer、Jeff Dean 并列），过去十年深度学习多项突破的开创者之一。他几个判断很值得听：

关于记忆与持续学习，他认为最有动能的方向是让 agent 把知识写进文件系统——"把你的想法写进文件、组织成目录和文件夹"，再配上基础检索机制。他直言模型的权重还没"追上"这种用法，但这种非参数化的记忆比把知识塞回权重要实用得多，原因很现实："要给规模化服务的同一个模型、为不同用户配不同的记忆权重，会非常痛苦。"他把这视为可能像一年半前"推理模型"那样的范式转变。

关于 RL 的下一个战场，他点出一个根本矛盾：下围棋这种环境每走几步就进入全新局面，等于免费产生无限训练数据；但 LLM 是数据受限的，"无限复杂性的来源并不清楚"。不过他对"模型当裁判"抱有希望——评估一个解法往往比创造它更容易（就像 NP 难问题难解易验证），这让我们有望在无法写出明确验证器的领域也能训练。

他还提到一个自己钟爱的评测方法：给模型一份它从没见过的游戏（比如《文明》）说明书，看它能否读懂规则、并在游玩中越玩越好——这考验的正是他最看重的"元能力"：学习与适应本身，而非成为某个领域的专才。

谈到 AGI，他的态度很坦诚："如果七年前让我拿到现在这个模型，我大概会宣布这就是 AGI。"在他看来，按几年前的定义，"某种意义上 AGI 已经到了"，只是还没到他想要的那种程度——而缺的那一块，正是真正从经验中学习的能力。
